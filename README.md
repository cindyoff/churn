# Étude du "churn" (rétention client)
Projet d'analyse exploratoire et de modélisation machine learning (ML) sur la rétention clients dans une banque. 

# Intérêts
Étude menée ici pour connaître les caractéristiques les plus pertinentes dans la rétention client au sein d'une banque. Plusieurs modèles de ML sont mobilisés et entraînés pour sélectionner le modèle le plus pertinent et donc tirer des conclusions appropriées au contexte. Chaque modèle, économétrique et ML, est suivi d'une analyse de performance et de robustesse, dans le cas de la régression logistique. Cette analyse post-entraînement et test permet de contester ou corroborer la légitimité des modèles sélectionnés dans notre environnement d'étude.
